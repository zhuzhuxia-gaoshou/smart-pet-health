## 0. 既有体系速查（实现者对照用）

- 色：`--bg/--surface/--surface-2/--border/--text/--text-2/--text-3`；`--accent`（品牌橙 #C2703D，**只许边框/图标/图表**）；`--accent-strong`（#A85A2E，实色白字专用）；状态色 `--success/--warn/--danger/--medication` + 各 `-soft` 底；`--on-accent`（实色底上的文字，暗色为深字）
- 形：`--r-btn 8 / --r-card 14 / --r-modal 16 / --r-pill 999 / --r-sm 10`
- 动：`--dur 180ms / --dur-fast 120ms / --dur-slow 220ms`，唯一缓动 `var(--ease)` = cubic-bezier(.2,0,0,1)
- 影：`--shadow-xs/sm/card/pop/deep`
- 可复用组件：`.btn(.primary/.sm/.ghost/.danger/.solid-danger/.loading)`、`.card/.card-pad/.card-title`、`.rec-row/.reminder-item/.activity-item` 列表行家族、`.badge(.healthy/.attention/.ill/.plain)`、`.chip`、`.wc-tip`（悬停提示卡）、`.wc-stat`（小统计格）、`.wc-pill`（分段控件）、`.skel/.skel-row/.sk-av/.sk-line(.w40/.w60)`、`.empty-state(.big/h3/p)`、`.empty-hint`、`.modal-overlay/.modal(.wide)/.form-grid/.form-field(.full)/.modal-actions`、`.med-group`（小节标题）、`.tl-del/.tl-ops`（行内文字按钮）、`.mon-*`（本次新增，见下）
- 无障碍补丁会自动：给 `role=button` 元素补 Enter/Space、管理弹窗焦点与 Tab 陷阱、同步 `.tab-btn/.detail-tab` 的 aria-selected、label 关联。**键盘委托白名单 `CARD` 常量需追加新可点行**（见 §5 红线）。

## 1. 新增 token 清单

只新增 2 个变量（亮暗各一套值）。追加到 `:root` 与 `html[data-theme="dark"]` 各 2 行。

| 变量 | 亮值 | 暗值 | 用途 |
|---|---|---|---|
| `--diet-wet` | `#2E6273` | `#7FB8C9` | 饮食类型「湿粮」徽章文字/图标色（亮：对 soft 底 ≈6.3:1；暗：对 surface ≈7.4:1，AA 达标） |
| `--diet-wet-soft` | `rgba(46,98,115,.10)` | `rgba(127,184,201,.14)` | 湿粮徽章底色 |

**不再新增其他颜色**，理由与映射：

- 记账五分类 → `medical:var(--accent-strong)`、`food:var(--success)`、`supply:var(--warn)`、`grooming:var(--medication)`、`other:var(--text-3)`。色相分离（陶土深橙/绿/琥珀/紫/暖灰），条形填充对卡片底 ≥3:1（非文本图形标准），徽章文字对 soft 底 ≥4.5:1。
- 日历圆点四色 → 逾期 `var(--danger)`、临期 `var(--warn)`、常规待办 `var(--text-3)`、用药进行中 `var(--medication)`（亮暗值全部既有）。
- 饮食其余四类 → kibble 用 accent 系、treat 用 warn 系、raw 用 danger 系、other 直接复用 `.badge.plain`。
- 洗护/紫系 soft 底缺失时用 `color-mix(in srgb, var(--medication) 12%, transparent)`（仿 `.med-dot` 光环写法），不新开 token。

JS 侧建常量表（仿 `TYPE_COLOR`）：

```js
const EXP_LABEL  = { medical:'医疗', food:'粮食', supply:'用品', grooming:'洗护', other:'其他' };
const EXP_COLOR  = { medical:'var(--accent-strong)', food:'var(--success)', supply:'var(--warn)', grooming:'var(--medication)', other:'var(--text-3)' };
const EXP_SOFT   = { medical:'var(--accent-soft)', food:'var(--success-soft)', supply:'var(--warn-soft)',
                     grooming:'color-mix(in srgb, var(--medication) 12%, transparent)', other:'var(--surface-2)' };
const DIET_LABEL = { kibble:'干粮', wet:'湿粮', treat:'零食', raw:'生骨肉', other:'其他' };
const DIET_COLOR = { kibble:'var(--accent-strong)', wet:'var(--diet-wet)', treat:'var(--warn)', raw:'var(--danger)', other:'var(--text-2)' };
const CAL_DOT    = { overdue:'var(--danger)', soon:'var(--warn)', todo:'var(--text-3)', med:'var(--medication)' };
```

## 5. 给实现者的红线提醒

**必须复用（禁止另造）**
1. 弹窗一律 `openModal/closeModal`（含无障碍包装）；表单一律 `.form-grid/.form-field`；保存时序一律 `flashSaved → 450ms → closeModal → toast`（参照 `submitMed`）。
2. 列表行一律 `.rec-row` 家族 + 既有 hover 三连（surface-2 底 / border / translateX(2px)）；新类 `.exp-row` 只加结构、**把选择器追加进 `.rec-row` 既有规则组**，不重写过渡。
3. 空态一律 `.empty-state` 三段式（图标→事实→出路→行动按钮）；轻提示一律 `.empty-hint`；等待 >300ms 一律 `.skel` 家族。
4. 悬停提示卡一律 `.wc-tip`（含 `.t-d` 子结构），定位算式照抄 `wcHover()`。
5. 小统计格一律 `.wc-stat`；分段/图例小标题一律 `.med-group`；行内文字按钮一律 `.tl-del`（含 24px 热区补丁）。
6. toast 一律三态 `toast(text, level)`；危险确认一律 `.btn.solid-danger` + 说明文案。

**动效禁区**
7. 全站唯一缓动 `var(--ease)`；时长只用 `--dur-fast/--dur/--dur-slow` 三档，任何新过渡 ≤220ms（`.btn:active` 的 70ms、modal 出场 150ms 除外，均为既有值）。
8. 动画属性只许 `transform/opacity`（卡片 -2px 上限、按钮 hover 不上浮、行位移 translateX(2px)）；禁止 width/height/top/left 动画（shimmer/ripple 既有动画除外）。
9. 不引入任何新 keyframes；圆点脉冲 `.pulse` 仅限既有 `.rem-dot.danger`，日历逾期点**不做**脉冲（一格多点时节奏混乱）。
10. `prefers-reduced-motion` 全局媒体查询已兜底，勿在新组件里写覆盖。

**冒烟测试生命线（改前必读，AGENTS.md）**
11. 单个 `<script>` 块不拆；`getState/go/renderLibrary/renderDashboard/switchTab/api/refreshData/sendChat/toggleTheme/openDetail/$/renderMemories/renderMemTimeline` 13 个顶层函数名不改（新增 renderLedger/renderCalendar 等为追加，不触碰）。
12. `data-theme` + localStorage `pet-theme` 机制不动；**新增 token 必须亮暗两套同时写**。
13. 顶栏页签文本扩为 6 项后，**同步修改 `dev/smoke.test.js` 页签断言**再跑 `node dev/smoke.test.js`（79/79 + 欢迎页 10/10 必须保绿）。
14. `#weight-chart .wc-dot ≥4` 且 `svg path ≥2` 的断言不可破坏：记账条形图放 `#exp-chart` 独立容器、不进 `#weight-chart`，互不污染。
15. 无障碍补丁的键盘委托常量 `CARD`（约 L2496）追加 `.cal-cell,.exp-row`；`.cal-cell` 的 aria-label 必须含日期与事项摘要（读屏用户没有圆点视觉）。
16. 品牌橙 `--accent` 只许边框/图标/图表填充；任何实色底白字（含 `.chip.on`、徽章实色变体）一律 `--accent-strong` + `--on-accent`。
17. `.chip.on` 是全站通用扩展：AI 助手建议 chips、memories 宠物 chip 均共用基类，选择器写 `.chip.on` 而非新组件名，避免样式分叉。
