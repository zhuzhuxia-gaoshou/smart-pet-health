## A2 提醒重复规则

- 迁移：`health_records` 加 `repeat_rule TEXT DEFAULT ''`，取值 `''|daily|weekly|monthly|yearly`（**补 yearly：疫苗年免是宠物场景刚需**）
- `RecordIn` 加 `repeat_rule` 可选字段 + 白名单校验
- **新端点 `POST /api/records/{id}/complete`**，语义 =「本轮已做」：
  1. 当前记录 `next_date` 置空（本轮闭环，退出提醒列表，历史保留）
  2. **插入新记录**：同 type/title，`date`=今天，`note` 追加"（周期生成）"，`repeat_rule` 继承，`next_date`=滚动结果
  3. 滚动基准 = `max(今天, 原next_date)`：逾期完成从今天起算（节奏重置），提前完成从原到期日起算（保持节奏）
  4. 月末钳制：1月31日 monthly → 2月28日；yearly 润年 2月29 → 平年 2月28
- 前端：提醒卡加「完成」按钮；记录表单加重复周期下拉；toast 提示"已生成下一轮（日期）"

## A3 用药记录

```sql
CREATE TABLE IF NOT EXISTS medications(
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  pet_id INTEGER, name TEXT NOT NULL,
  dosage TEXT DEFAULT '', frequency TEXT DEFAULT '',
  start_date TEXT, end_date TEXT,
  status TEXT DEFAULT 'active',   -- active|finished
  note TEXT DEFAULT '',
  created_at TEXT DEFAULT (datetime('now','localtime')),
  FOREIGN KEY(pet_id) REFERENCES pets(id) ON DELETE CASCADE
);
```

- API：`GET/POST /api/pets/{id}/medications`，`PUT/DELETE /api/medications/{id}`（停药走 PUT status=finished）
- 种子数据与现有健康记录呼应：布丁耳药水（外耳炎就诊开的）、可乐益生菌、翠翠换羽期电解质（已结束）
- `reset_demo_data()` 删除清单加入 medications
- AI：`tools.query_medications(pet_name)`（在用/已结束分组输出）+ 注册 StructuredTool + TOOL_META + 系统提示词提及
- 前端：档案详情「用药」页签（进行中在前），表单按物种无关设计

## A4 新增栏目（记账/日历/饮食/分诊 · 2026-09-17 夜）

- **规格来源**：`docs/夜间设计规格_新增栏目.md`（UI设计师产出，2 个新 token、22 个类，其余全部复用既有体系）。实现遵循规格，以下为规格之外的取舍记录。
- **`.diet-row` 不进 hover 三连、不进键盘委托**：饮食流水行不可点（操作靠行内「编辑/删除」），`.rec-row` 的 `translateX(2px)` 位移会错误暗示可点；键盘上不给 `role=button`，Tab 直接落到行内真按钮（`.tl-ops` 有 `:focus-within` 显现）。
- **日历当日卡加了规格外的「关闭」按钮**：与全站弹窗必有退出按钮的习惯一致；规格原文只有「＋ 记一笔」。
- **日历已做记录不占圆点**：四色圆点严格留给 逾期/临期/待办/用药（规格定死），已做记录以 `✓N` 小字标示在圆点行尾，不引入第五色。
- **记账条形图空类 4px 灰条、整月空数据给 empty-hint**：规格只说"空类固定灰条"，全空时 5 条灰条视觉无意义，改为一句引导文案。
- **记账/饮食/当日卡三处「＋ 记一笔」文案区分**（门禁审查提出）：记账保留「记一笔」（花销语境由页面标题锚定）、饮食改「记一餐/记第一餐」、日历当日卡改「＋ 健康记录」。
- **`.chip.on` 做成全站通用选中态**（`:349`）：实色底一律 `--accent-strong + --on-accent`，暗色自动反转；症状分诊 chips、未来任何可选中 chip 共用，避免样式分叉。
- **生骨肉徽章单独加深**：`--danger` 对 `danger-soft` 底实测 4.45:1（12px 小字 AA 需 4.5），新增 `--diet-raw`（亮 #A03A30 / 暗 #EE9188）而非硬编码，延续「颜色必入 token」纪律。
- **月份分组组头复用 `.exp-group-head`**：健康记录页按月分组与记账按宠物分组同一组件语言，全站"分组列表"只有一种视觉。
- **记录页分组用月份、记账页分组用宠物**：同一组件两种维度是刻意的——记录是时间轴心智、账目是"谁花的"心智。
