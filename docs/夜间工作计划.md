## 二、主线 A：功能开发（约 5.5 小时）

### A1. 体重趋势折线图（~1.5h）
- 后端：`GET /api/pets/{id}/weight-trend` 返回按时间排序的体重序列（复用健康记录数据，不新表）
- 前端：纯 SVG 手写折线图（不引第三方库）——坐标轴、数据点悬停读数、最近 N 次区间切换
- 与已有"体重 AI 解读"打通：图表旁一键解读，解读上下文带上完整趋势
- 验收：档案详情页见图，悬停有读数，AI 解读引用趋势数据；冒烟新增 ≥2 条用例
- commit：`feat: 体重趋势折线图——SVG手绘图表·悬停读数·AI解读接入趋势上下文`

### A2. 提醒重复规则（~1.5h）
- 后端：reminders 表加 `repeat_rule` 字段（none/daily/weekly/monthly），完成时自动生成下一次（含月末边界：1月31日→2月28日）
- 前端：提醒表单加重复选择；列表重复图标；完成时 toast「已生成下一次提醒」
- 验收：三种周期各测一条，完成后下一条自动出现；老数据无字段兼容不炸；冒烟新增 ≥3 条
- commit：`feat: 提醒重复规则——每天/每周/每月自动续期·月末边界处理`

### A3. 用药记录（~2.5h）
- 后端：新表 `medications`（宠物id/药名/剂量/频率/开始结束日期/状态/备注）+ CRUD API
- 前端：档案详情新增「用药」页签，进行中/已结束分组，按新微交互规范写 UI
- AI 挂接：新增「查用药」工具；健康分析工具的上下文纳入在用药信息
- 验收：增删改查全通、AI 能答「毛毛现在吃什么药」；冒烟新增 ≥4 条
- commit：`feat: 用药记录——medications表+用药页签+查用药AI工具`（可拆 2~3 个）

### A4. 弹性：健康记录类型筛选 + 时间线视图（时间富余才做）

## 三、主线 B：前端美化（约 4 小时）

### B1. 设计 token 化（~2h，先做——新功能直接用新规范，不返工）
- 「UX架构师」出 token 方案：色彩（奶油底 #FBFAF7 / 陶土橙 #C2703D 全阶）/ 间距 / 排版（Fraunces 标题体系）/ 圆角 / 阴影 / 响应式断点
- 我落地：`index.html` 内联 CSS 魔法数字全部收敛为 CSS 变量，产出 token 清单文档存 `docs/`
- commit：`refactor: CSS设计token化——色彩/间距/排版/圆角/阴影变量化`

### B2. 全局微交互体系（~2h，风格：全局优雅克制，Notion 式）
- 「UI设计师」出全套交互态规格，统一缓动曲线与时长（全部 ≤220ms）
- 落地清单：
  - 按钮：hover 微亮 → 按压 scale(0.98) → 焦点环，统一到组件类
  - 卡片：hover 柔和浮起（阴影过渡）
  - 弹窗：入场淡入+轻微上移；遮罩过渡
  - toast：滑入淡出，成功/警告/错误三态
  - 列表行：hover 底色过渡
  - 加载态：骨架屏统一替代裸 loading
  - 表单：输入聚焦边框过渡、错误抖动提示
- commit：`feat: 全局微交互体系——按钮/卡片/弹窗/toast/骨架屏统一交互态`

### B3. 美化第二波（~与门禁审查合并进行）
- 每种列表的空状态：文案 + 图形统一打磨（不是光秃秃一行字）
- 「界面完成度门禁审查员」代码模式逐屏审 → 修 🔴🟡
- 弹性：欢迎页（welcome.html）按新规范打磨

## 九、执行纪律

1. **每个功能独立中文 commit**（格式参照 git log），commit 即存档点，出问题可回退
2. **冒烟测试每阶段保绿**，新功能必须带新用例（目标 46→55+）
3. **不主动 push**，push 等用户醒来决定
4. **`.env` 绝不进 git、绝不在回复中输出**
5. **浏览器纪律：整晚最多开 2 次**（P0 确认服务一次，收尾可选一次）；验证靠 curl + 子智能体读代码；复杂界面检验留给用户白天
6. AI 供应商故障不阻塞：相关断言可跳过，晨间清单里标注「待实测」
7. 中文工作语言；设计语言守住 Notion 暖色极简（#FBFAF7 / #C2703D / Fraunces / ≤220ms）
