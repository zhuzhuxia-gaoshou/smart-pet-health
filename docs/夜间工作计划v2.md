# 🌙 夜间工作计划 v2（2026-09-16 晚）

> 执行方式：通宵自主推进，用户可随时叫停；允许使用全部六个子智能体
> 铁律：**功能开发 + 界面美观是主要任务**；验证靠 curl + 子智能体读代码，浏览器留用户白天验收

---

## 一、主线任务（保底必做）

### M1 · 花费记账（新顶栏栏目，~4h）
- **后端**：新表 `expenses`（id / pet_id 可空=家庭共同 / date / category: medical|food|supply|grooming|other / amount REAL / note / created_at）+ 索引；`GET/POST /api/pets/{id}/expenses`、`GET /api/expenses?year=&month=&pet_id=&category=`（聚合：总数/分类合计/按宠物合计）、`PUT/DELETE /api/expenses/{id}`；种子数据与现有记录呼应（狂犬疫苗¥120、外耳炎就诊¥260、耳药水¥45、猫粮¥380…）；重置清单纳入
- **前端**：顶栏第 5 页签「记账」；月份 ‹ › 切换 + 本月合计卡 + 分类 SVG 条形图（复用体重图风格 token）+ 按宠物分组流水 + 增改删弹窗；空状态套 empty-state 体系
- **AI**：新工具 `query_expenses(宠物名?, 年份月份?)` → 健康分析师工具子集；降级路由关键词「花了/开销/多少钱/花费/记账」→ health_analyst
- **测试**：冒烟 +5 条（CRUD 闭环/聚合正确/空态）；eval_cases +2 条（「可乐这个月花多少钱」「今年医疗开销大头」）

### M2 · 健康日历（新顶栏栏目，~3h）
- **后端**：零新表；`GET /api/calendar?year=&month=` 聚合三源：health_records.next_date（待办：逾期红/临期琥珀）、health_records.date（已做）、medications 起止（进行中药疗）
- **前端**：顶栏第 6 页签「日历」；标准月历格子（今天高亮/非本月置灰），日期圆点分级 = 逾期红·临期琥珀·常规灰·用药紫；点某天弹当日事项卡（复用 modal），卡内「完成提醒 / 查看宠物 / 记一笔」直达；顶部 ‹ 月份 › + 「回到今天」
- **设计契约**：沿用 Notion 暖色极简；格子间距/圆角走 token；hover 克制（底色过渡 ≤220ms）
- **测试**：冒烟 +4 条（聚合含逾期+临期/月历格子数/当日卡片渲染/月切换）

### M3 · 界面统一打磨（~1.5h）
- 顶栏 4→6 页签后的导航视觉（间距/激活态），确认不挤
- 两个新页与现有页的标题层级/空态/微交互完全对齐
- 「UI设计师」子智能体出两页规格 → 我实现 → 门禁审查员代码模式复查

## 二、安全与合规（必做，~0.5h）

- 冒烟生命线同步：页签文本断言扩为 6 项、`[role=tab]===6`；新函数不进 13 个受保护名单
- 金额输入校验（>0、两位小数）、`422` 中文提示沿用现有 handler
- 花费记账属敏感汇总数据：AI 工具只读；无删除导出以外的写路径
